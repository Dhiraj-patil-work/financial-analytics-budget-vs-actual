# FP&A Financial Analytics — Budget vs Actual

## 📌 Project Overview

An end-to-end Financial Data Analytics project focused on
Budget vs Actual analysis, variance analysis, expense trends,
budget utilization and financial forecasting.

The project demonstrates the complete workflow from raw
financial data preparation to SQL analysis, Power BI
dashboarding and management recommendations.

---

## 🎯 Business Problem

Management needs visibility into financial performance
against approved budgets.

The objective is to identify:

- Budget vs Actual performance
- Unfavorable expense variances
- Major cost drivers
- Department performance
- Regional budget utilization
- Monthly spending trends
- Potential future spending patterns

- Monthly Spending
- Department Variance
- Category Spending
- Regional Performance

---

## 🧮 Financial Formulas

Variance:

Actual − Budget

Variance %:

(Actual − Budget) / Budget × 100

Budget Utilization:

Actual / Budget × 100

---

## 🔍 Key Business Questions

1. Which departments have the highest unfavorable variance?
2. Which categories drive actual spending?
3. Which regions have high budget utilization?
4. How does spending change over time?
5. Are unfavorable variances recurring or isolated?
6. Which areas require management attention?
